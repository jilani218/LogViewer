Query syntax

The filter box accepts free text plus Android Studio–style key:value tokens. Tokens combine with AND. Prefix with - to exclude.

  • tag:MyTag — substring match on tag
  • tag~:^MyTag$ — regex match on tag
  • package:com.example or pkg: — match package/UID column
  • pid:1234, tid:5678
  • level:W or level:warn — exact level
  • min:I — minimum level (V<D<I<W<E<A)
  • message:"hello world" or msg: — quoted phrase
  • "exact phrase" — phrase match in any field
  • /regex/ — body regex (toggle .* applies regex to plain text too)
  • -tag:Choreographer — exclude

Shortcuts: Cmd/Ctrl+O open · Cmd/Ctrl+F focus filter · Cmd/Ctrl+L clear · Cmd/Ctrl+End jump to bottom · Esc clear filter

Live device streaming

To stream logs directly from a connected Android device, run the small bridge that ships next to this HTML file:

cd /path/to/this/folder
node adb-bridge.js

It exposes http://localhost:8037. Make sure adb is on your PATH (or set ADB=/path/to/adb). USB debugging must be enabled on the device.

Tip: open http://localhost:8037/ instead of the local file — same UI, no CORS prompts.
